# Romantic Communication Site

This is a web application that allows users to send romantic messages to their partners via WhatsApp.

## Deployment on Vercel

To deploy this application to Vercel, follow these steps:

1.  **Fork this repository.**
2.  **Create a new project on Vercel.**
3.  **Connect your Vercel project to your forked repository.**
4.  **Configure the environment variables.**
    *   `VITE_SUPABASE_URL`: Your Supabase project URL.
    *   `VITE_SUPABASE_ANON_KEY`: Your Supabase anonymous key.
5.  **Deploy!**

Vercel will automatically detect the `vercel.json` file and deploy the application.
